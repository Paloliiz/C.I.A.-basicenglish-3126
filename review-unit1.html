📂 CODE 1: คำศัพท์อาชีพ (Jobs)

จำแค่ "คีย์เวิร์ด" ก็ตอบได้แล้ว!

  • 👮‍♂️ security guard (รปภ.): ใบ้คำว่า protects buildings (ปกป้องอาคาร)
  • ✈️ travel agent (พนักงานจัดทัวร์): ใบ้คำว่า plan holidays (วางแผนวันหยุด)
  • ❤️ heart surgeon (ศัลยแพทย์หัวใจ): ใบ้คำว่า operations on hearts (ผ่าตัดหัวใจ)
  • 🗿 living statue (คนแต่งตัวเป็นรูปปั้น): ใบ้คำว่า body paint (ทาสีตัว)

คำศัพท์จิปาถะที่ห้ามพลาด

  • tartan skirt = กระโปรงลายสก๊อตแบบชาวสกอตแลนด์
  • short-sleeved top = เสื้อแขนสั้น (ใส่ตอนอากาศร้อน hot)
  • wrinkles = รอยย่นบนใบหน้าคนแก่ (Old people)

โจทย์: Eric Sprague has green tattoos all over his body to look like a ____________.

วิเคราะห์: มีรอยสักสีเขียวเต็มตัวเพื่อให้ดูเหมือนอะไร? ➔ ตอบ lizard (กิ้งก่า) 🦎

📂 CODE 2: ลักษณะนิสัย (Character)

เจอโจทย์ถามนิสัย ให้แปลอาการที่เขาเป็น แล้วจับคู่ให้ตรงกัน

  • 🤬 selfish (เห็นแก่ตัว): ใบ้คำว่า cares about himself (แคร์แต่ตัวเอง)
  • 🤝 outgoing (เข้าสังคมเก่ง): ใบ้คำว่า loves meeting new people (ชอบเจอคนใหม่ๆ)
  • ⚖️ honest (ซื่อสัตย์): ใบ้คำว่า trust (ไว้ใจได้)
  • 🧘‍♂️ patient (ใจเย็น/อดทน): ใบ้คำว่า ทำงานกับ children (เด็กๆ ต้องใช้ความใจเย็นสูง)

📂 CODE 3: Tense แฝดจอมป่วน

1. Present Simple (ทำเป็นกิจวัตร/ตารางเวลา)

สูตร: กริยาเติม s/es (ถ้าประธานคนเดียว)

คำบอกใบ้: every day, on Sundays, sometimes, usually

ตัวอย่าง: We go on holiday every August. (ไปทุกๆ เดือนสิงหา)

2. Present Continuous (กำลังทำตอนนี้/แผนที่วางไว้ชัวร์ๆ)

สูตร: is/am/are + V.ing

คำบอกใบ้: now, tomorrow, at 7 pm.

ตัวอย่าง: Dad is walking the dog. (กำลังพาน้องหมาเดินเล่นอยู่ตอนนี้)

คำกริยาที่บอก "ความรู้สึก/ความคิด" ห้ามเติม -ing เด็ดขาด!

เช่น want (ต้องการ), like (ชอบ), love (รัก)

❌ I am wanting to buy jeans. (ผิด)

✅ I want to buy jeans. (ถูก)

📂 CODE 4: ขั้นกว่า (Comparatives)

ใช้เปรียบเทียบของ 2 สิ่ง (มักจะมีคำว่า than ตามหลังเสมอ)

  • คำสั้นๆ: ให้เติม -er + than
    เช่น hot ➔ hotter than (ร้อนกว่า) / hard ➔ harder than (หนักกว่า)
  • คำยาวๆ (3 พยางค์ขึ้นไป): ให้ใส่ more + คำยาว + than
    เช่น beautiful ➔ more beautiful than (สวยกว่า)

โจทย์: Jane is ____________ than Mary. (beautiful)

วิธีคิด: มีคำว่า than = ขั้นกว่า / beautiful เป็นคำยาว = ใช้ more

➔ ตอบ more beautiful

📂 CODE 5: ขั้นสุด (Superlatives)

ใช้บอกว่า ที่สุดในกลุ่ม (มักจะมีคำว่า the นำหน้าเสมอ)

  • คำสั้นๆ: ให้ใส่ the + คำเติม -est
    เช่น the hottest (ร้อนที่สุด)
  • คำยาวๆ: ให้ใส่ the most + คำยาว
    เช่น the most intelligent (ฉลาดที่สุด)

🚨 ตัวหลอกประจำคดี (คำเปลี่ยนรูป)

คำบางคำไม่เติม -er หรือ -est แต่จะเปลี่ยนร่างไปเลย!

  • good (ดี) ➔ better (ดีกว่า) ➔ best (ดีที่สุด)
  • bad (แย่) ➔ worse (แย่กว่า) ➔ worst (แย่ที่สุด)

เช่น He is the worst singer in the world. (นักร้องที่แย่ที่สุด)

📂 CODE 6: Too & Enough

สองคำนี้เจอบ่อยมาก ความหมายต่างกันชัดเจน!

  • 🙅‍♂️ Too + Adjective (มากเกินไป):
    ใช้ในความหมายเชิงลบ คือมากเกินไปจนทำไม่ได้/ไม่ดี
    เช่น Jamie is too tired to do any work. (เจมี่เหนื่อยเกินไปที่จะทำงาน)
  • 👍 Adjective + Enough (เพียงพอ):
    ใช้ในความหมายเชิงบวก คือมีคุณสมบัติพอที่จะทำได้ (จำไว้ว่า enough ต้องอยู่ข้างหลังเสมอ!)
    เช่น Sam is clever enough to become a doctor. (ฉลาดพอที่จะเป็นหมอ)

โจทย์: This dress is ____________ for me. Have you got it in a bigger size?

วิธีคิด: เขาขอดู "ชุดไซส์ใหญ่ขึ้น" แสดงว่าชุดที่ใส่อยู่มันต้อง "เล็กเกินไป" ➔ ตอบ too small
