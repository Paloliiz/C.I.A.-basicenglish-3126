# SPARK 3 Review — เว็บแอปทบทวนภาษาอังกฤษ ม.3

เว็บแอปสำหรับให้นักเรียนทบทวนเนื้อหาวิชา อ23101 ภาษาอังกฤษพื้นฐาน ชั้นมัธยมศึกษาปีที่ 3
ด้วยตนเอง สรุปจากเอกสารประกอบการเรียน (SPARK 3) ตลอดภาคเรียนที่ 1/2569 พร้อมระบบฝึกทำโจทย์
แบบสุ่มและข้อสอบจำลองคู่ขนานกับข้อสอบปลายภาค

เป็นเว็บไซต์ static ล้วน (HTML/CSS/JavaScript) ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล
จึงอัปโหลดขึ้น GitHub Pages แล้วใช้งานได้ทันที เปิดได้ทุกอุปกรณ์ โดยเฉพาะมือถือ

## โครงสร้างไฟล์

```
index.html          หน้าแรก / แดชบอร์ด
review.html          ทบทวนเนื้อหา (คำศัพท์ ไวยากรณ์ บทอ่าน แยกตามหน่วย)
quiz.html             ฝึกทำโจทย์แบบสุ่ม เลือกหมวด/หน่วย/จำนวนข้อได้เอง
exam.html             ข้อสอบจำลองคู่ขนาน 60 ข้อ จับเวลา 60 นาที
assets/
  css/style.css        ธีมและสไตล์ทั้งเว็บไซต์
  js/data.js            เนื้อหาทั้งหมด (คำศัพท์ ไวยากรณ์ บทอ่าน คลังข้อสอบ) — แก้ไข/เพิ่มเนื้อหาที่ไฟล์นี้
  js/app.js              ฟังก์ชันพื้นฐานที่ใช้ร่วมกันทุกหน้า (เมนู, บันทึกคะแนนลงเครื่อง)
  js/review.js           สร้างหน้าทบทวนเนื้อหาจาก data.js
  js/quiz-engine.js      ระบบคำถาม/ตรวจคำตอบ ใช้ร่วมกันทั้งหน้า quiz และ exam
```

## วิธีนำขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่น ชื่อ `spark3-review`)
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในนี้ขึ้น repository (ลาก-วางบนหน้าเว็บ GitHub หรือใช้ `git push` ก็ได้)
   - **สำคัญ:** ให้ `index.html` อยู่ที่ระดับบนสุดของ repository (ไม่ต้องอยู่ในโฟลเดอร์ย่อย)
3. ไปที่ **Settings → Pages**
4. ในหัวข้อ **Build and deployment → Source** เลือก **Deploy from a branch**
5. เลือก branch เป็น `main` (หรือ branch ที่อัปโหลดไว้) และโฟลเดอร์เป็น `/ (root)` แล้วกด **Save**
6. รอประมาณ 1–2 นาที เว็บไซต์จะพร้อมใช้งานที่
   `https://<ชื่อบัญชี-github>.github.io/<ชื่อ-repository>/`
7. แชร์ลิงก์นี้ให้นักเรียน หรือติดไว้ในกลุ่มไลน์/Google Classroom ของห้องเรียน

ไม่ต้องตั้งค่า build step, ไม่ต้องติดตั้ง Node/npm ใด ๆ — เป็นไฟล์ static ล้วน

## การแก้ไข/เพิ่มเนื้อหา

เนื้อหาทั้งหมด (คำศัพท์ ไวยากรณ์ บทอ่าน คลังข้อสอบ) อยู่ในไฟล์เดียวคือ
`assets/js/data.js` แก้ตรงนี้ที่เดียว หน้าเว็บทุกหน้าจะอัปเดตตามอัตโนมัติ:

- **`VOCAB`** — คำศัพท์ แบ่งตาม unit → topic → คำ (word/meaning/example)
- **`GRAMMAR`** — ไวยากรณ์ แบ่งตาม unit → topic (title + เนื้อหา HTML สั้น ๆ)
- **`READING`** — บทอ่านเต็ม พร้อมคำศัพท์สำคัญ (glossary)
- **`BANK`** — คลังข้อสอบสำหรับหน้า "ฝึกทำโจทย์" (สุ่มข้อ), แยกเป็น vocabulary / grammar / reading
- **`MOCK_EXAM`** — ข้อสอบจำลอง 60 ข้อคงที่ (ดึงจาก `BANK` ส่วนแรกของแต่ละหมวด)

โครงสร้างข้อคำถามแต่ละข้อ:
```js
{ q: "โจทย์คำถาม ______ ", options: ["ตัวเลือกที่ถูก", "ตัวลวง1", "ตัวลวง2", "ตัวลวง3"], correct: 0 }
```
ไม่ต้องเรียงคำตอบให้กระจาย A/B/C/D เอง — ระบบจะสุ่มลำดับตัวเลือกใหม่ทุกครั้งที่แสดงผลให้อัตโนมัติ
(ใส่คำตอบที่ถูกไว้ตำแหน่งไหนก็ได้ ระบบจัดการให้)

## หมายเหตุเรื่องข้อมูล

คะแนนและประวัติการฝึกทำโจทย์ที่แสดงในหน้าแรกถูกบันทึกไว้ใน `localStorage` ของเบราว์เซอร์
นักเรียนแต่ละคนบนอุปกรณ์ของตัวเอง — ไม่มีการส่งข้อมูลไปเก็บที่เซิร์ฟเวอร์ใด ๆ และครูจะไม่เห็น
คะแนนของนักเรียนจากส่วนกลาง (เหมาะสำหรับการทบทวนด้วยตนเอง ไม่ใช่ระบบเก็บคะแนนเพื่อประเมินผล)
